# Projet Bloc

Ce depot contient plusieurs exercices de mise en page HTML/CSS organises par blocs.

## Objectif

## Lancer le projet

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir le fichier HTML du bloc a visualiser.
3. Lancer le fichier dans un navigateur.
