## Objectif

Reproduire et entrainer des interfaces web en separant chaque exercice dans un dossier dedie.

## Apercu du projet

Chaque bloc contient au minimum :

- un fichier HTML
- un fichier CSS
- des assets partages dans les dossiers `images` et `icone`

## Demarrage rapide

1. Ouvrir le dossier du projet dans VS Code.
2. Ouvrir un fichier HTML (exemple : [bloc 1/Bloc1.html](bloc%201/Bloc1.html)).
3. Lancer la page dans le navigateur (double-clic ou extension Live Server).
